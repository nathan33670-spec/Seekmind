# ADR-0003 — Android 11 (API 30) minimum

| | |
|---|---|
| **Statut** | Accepté |
| **Date** | 2026-11-12 |

## Contexte

L'OCR de repli repose sur `AccessibilityService.takeScreenshot()`, qui capture l'écran en mémoire sans
la boîte de dialogue de `MediaProjection`. Cette API n'existe qu'à partir d'Android 11.

## Décision

`minSdk = 30`. `targetSdk = 36` (exigence de Google Play depuis le 31 août 2026). `compileSdk = 37`.

## Conséquences

- Un seul chemin de code pour la capture d'écran ; pas de mode dégradé « sans OCR ».
- `takeScreenshotOfWindow()` et le code d'erreur « fenêtre sécurisée » ne sont disponibles qu'à partir
  de l'API 34 : les versions 30 à 33 utilisent une heuristique (ADR-0008).
- Les appareils antérieurs à Android 11, minoritaires et pour la plupart trop limités pour l'inférence
  embarquée, ne sont pas servis.
- Les appareils Android 11 d'entrée de gamme existent en 32 bits : l'ABI `armeabi-v7a` est conservée.

## Alternatives écartées

- **API 26 à 29 sans OCR** : double la matrice de test pour une faible part du parc et une expérience
  dégradée (pas de texte dans les images et les vidéos).
- **`MediaProjection`** : boîte de dialogue système à chaque session, indicateur d'enregistrement
  permanent, service de premier plan ; contraire à l'esprit du produit.
